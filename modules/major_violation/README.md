# 重大違規績效資料整理模組

已完成資料標準化與第二階段「重大違規／行人路權嚴格口徑」分類分析；尚未加入網頁上傳流程與專用簡報。

## 已完成

- `data/schema.py`：不可變的 `ViolationRecord`、`ViolationSourceInfo`、`ViolationDataset`。
- `data/transformer.py`：欄位別名、民國／西元日期、時間、法條條項款目、道路及執法欄位標準化。
- `data/loader.py`：多份 `.xlsx/.xlsm` 批次讀取，保留各檔案成功、失敗、欄位對照與警告。
- 多檔合併目前不自動去重；每筆保留來源檔案、工作表與來源資料序。
- `analysis/rules.py`：九大重大違規、五大行人路權的版本化法條分類規則。
- `analysis/service.py`：期間篩選、類別件數、月／季趨勢、路段／行政區／時段排行與未分類檢核。

分類使用標準化後的條、項、款及必要文字條件，非來源檔名。第44條會同時列入「汽機車不暫停讓行人」與「路口不停讓行人」，兩組總數不得相加。嚴重超速、蛇行／惡意逼車目前明列為缺少可核對來源資料，避免把零件數誤報為零發生。

未來預計包含：

- `presentation/`：重大違規專用投影片與 TOKEN 生成
- `templates/`：重大違規報表模板

此模組不應直接修改事故資料分析的欄位或模板。
