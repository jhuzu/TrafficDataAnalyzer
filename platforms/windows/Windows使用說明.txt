交通資料分析工具（Windows 版）

適用：Windows 10／11（64 位元）。

一般使用（第一次）：
1. 安裝 Python 3.11 或更新版本：https://www.python.org/downloads/windows/
2. 安裝時請勾選「Add Python to PATH」。
3. 解壓整個專案資料夾。
4. 開啟 `platforms/windows/`，連按兩下「安裝Windows依賴.bat」，等待安裝完成。
5. 在同一資料夾連按兩下「啟動Windows版.bat」。瀏覽器會自動開啟工具。

平常使用：
- 連按兩下 `platforms/windows/啟動Windows版.bat`。
- 資料只在本機瀏覽器與 http://127.0.0.1:8765 間處理。
- 事故地圖需要網路下載 OpenStreetMap 底圖。

免安裝 EXE 封裝（供技術人員在 Windows 上製作）：
1. 完成上述首次安裝。
2. 連按兩下 `platforms/windows/打包Windows免安裝版.bat`。
3. 在 generated\TrafficDataAnalyzer_Windows_免安裝版.zip 取得可交付壓縮檔。

注意：
- 支援 .xlsx 與 .xlsm；舊版 .xls 請先以 Excel 另存為新格式。
- Windows 版 PowerPoint 匯出使用 Microsoft JhengHei 字型；請保留系統內建字型以維持中文輸出品質。
- 若顯示 8765 連接埠已使用，請關閉另一個工具視窗後再試。
